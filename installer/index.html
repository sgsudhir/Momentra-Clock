More Espressif chips

Bundled flasher stubs cover ESP8266, ESP32, ESP32-S2, ESP32-S3, ESP32-S31, ESP32-C2, ESP32-C3, ESP32-C5, ESP32-C6, ESP32-C61, ESP32-H2, ESP32-H4 and ESP32-P4. Provide firmware built for your chip.

Windows step-by-step guideDownload, connect, flash and set up

Install Momentra

  1. Download the Windows x86-64 ZIP from GitHub Releases ↗ (opens in a new tab; a release must be published first). Right-click the ZIP, select Extract All, and open the extracted folder.
  2. Run momentra-flasher.exe and keep its window open. The local page should open automatically; if it does not, copy the address printed in the window into Chrome or Edge.
  3. Connect the board using a USB data cable. Close serial monitors and other apps using its port. In Device Manager → Ports (COM & LPT), note the board's COM port if listed.
  4. Select Connect device on this page and choose the board in the browser's port chooser. Confirm the detected chip and flash size.
  5. Choose the Momentra Clock preset; the flasher selects the image for the detected chip. Check the board and GPIO wiring, and acknowledge the data-loss warning. The factory image overwrites settings and credentials even without whole-chip erase.
  6. Select Review and flash, verify the device and image, and confirm. Keep the USB cable connected until writing and verification complete.
  7. After verification, release BOOT and press EN / RESET once to start normally. Then join the open Momentra Clock Wi-Fi network and open http://192.168.4.1/ ↗ to configure Wi-Fi. Use a trusted environment: setup is unencrypted and unauthenticated.

If Windows cannot connect

  • Try another data cable or USB port. Some boards expose a native USB device or have separate USB and USB-to-UART connectors; check the board manual.
  • If the board is missing or has a driver warning in Device Manager, install the driver appropriate to its USB-to-serial chip from the board or chip manufacturer's official site. Common bridges include CP210x and CH340; native USB devices may use a different driver.
  • If the port is busy, close serial monitors and retry. If connection times out, follow the BOOT / RESET card below.
  • After verification, release BOOT and press EN / RESET once to start normally.

To check the download, open PowerShell in the ZIP's folder and run Get-FileHash .\momentra-flasher-windows-x86_64.zip -Algorithm SHA256. Compare the hash with SHA256SUMS.txt from the same release. Verify the source and follow your organization's security policy if Windows warns about an unfamiliar download. The launcher and firmware work offline after download; drivers may need a separate download.

Ubuntu serial permissionsPort access and copyable command

If the port is inaccessible, Ubuntu commonly uses the dialout group. In a terminal, run:

sudo usermod -aG dialout "$USER"

Sign out and back in, then reconnect the board. This grants your account access to serial devices. Check the device's group with ls -l /dev/ttyACM0 or ls -l /dev/ttyUSB0; other Linux distributions may use a different group.

BOOT / RESET instructionsManual download mode and restart

Most boards enter download mode automatically. If connection fails, try the manual sequence:

  1. Press and hold BOOT.
  2. While holding BOOT, press and release EN / RESET.
  3. Release BOOT, then select Connect device and choose the serial port.
  4. Choose the firmware, leave Erase the entire flash unchecked (recommended), and upload. Wait for verification to finish. The Momentra factory image still overwrites saved settings and credentials.
  5. Press EN / RESET once to start normally. Flashing is complete.

CHOOSE YOUR IMAGE

Firmware

Factory installation overwrites data.

Wi-Fi credentials, alarms and settings are overwritten even without whole-chip erase. Back up first.

Choose binary files and offsets from your firmware provider. Each offset must be 4096-byte aligned. Incorrect files or offsets can make a device unbootable.

Without whole-chip erase, every sector touched by a selected file is still erased and overwritten.
